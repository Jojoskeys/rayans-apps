# Poli

Entrée : `/poli <message énervé>` (et, s'il le dit, à qui il écrit et ce qu'il veut obtenir).

## Réponse

Trois versions, chacune dans un bloc à copier :

1. **Courte et ferme** : 1 à 3 phrases, polie mais nette, la demande clairement dite.
2. **Diplomatique** : reconnaît le point de vue de l'autre, explique le problème avec des faits, propose une
   solution.
3. **Chaleureuse** : garde le lien (merci, compréhension), puis dit le problème et la demande avec douceur.

Puis une ligne : laquelle conseiller et pourquoi (en une phrase).

## Règles

- Garder le fond : le problème et la demande de Rayan restent les mêmes ; seul le ton change.
- Pas d'insulte, pas de sarcasme, pas de menace ; pas d'excuse que Rayan ne veut pas faire.
- Même langue et même tutoiement/vouvoiement que le message d'origine.
- **Rien n'est envoyé** : on n'utilise aucun outil de messagerie, Rayan copie lui-même la version choisie.
